# 关于并发的对话

<div class="chap-en">A Dialogue on Concurrency</div>

<div class="chap-en">A Dialogue on Concurrency</div>

**教授**：就这样，我们来到了操作系统的三大支柱中的第二个：并发。

**学生**：我以为有四个支柱……？

**教授**：不，那是这本书旧版本里的说法。

**学生**：呃……好吧。那么，亲爱的教授，什么是并发？

**教授**：嗯，想象我们有一个桃子——

**学生**：（打断）又是桃子！你怎么老跟桃子过不去？

**教授**：读过 T.S. 艾略特的诗吗？《J. 阿尔弗雷德·普鲁弗洛克的情歌》，"我可有胆量吃一个桃子"，还有那些好玩的东西？

**学生**：哦，读过！高中英语课上学的。写得真棒！我特别喜欢那一段——

**教授**：（打断）跟那个没关系——我就是喜欢桃子。总之，想象桌上摆着很多桃子，还有很多人想吃。假设我们这么做：每个吃桃子的人先用眼睛锁定一个桃子，然后伸手去抓、去吃。这个做法有什么问题？

**学生**：嗯……看起来，你看到的桃子，别人可能也看到了。要是人家先到，等你伸手过去，桃子就没了！

**教授**：正是如此！那我们该怎么办？

**学生**：嗯，大概得想个更好的办法。也许排成一队，轮到你走到前面时，拿一个桃子，然后该干嘛干嘛去。

**教授**：很好！但你的办法又有什么问题？

**学生**：天啊，所有活都得我一个人干吗？

**教授**：是的。

**学生**：好吧，让我想想。嗯，原来的做法是大家一拥而上抢桃子，那样更快。但按我的办法，大家只能一个一个来，这样是对的，可慢了不少。最好的办法大概应该又快又对。

## 关于并发的对话

**教授**：你越来越让我刮目相看了。事实上，你刚刚已经把并发需要知道的一切都讲出来了！干得好。

**学生**：我讲了？我以为我们只是在聊桃子。别忘了，通常到这个时候，你该把话题扯回计算机上了。

**教授**：确实。恕我跑题了！人不能忘了具体的东西。嗯，事实是这样的：有一类程序，我们称之为多线程应用；每个线程有点像程序里四处活动的独立代理，代表程序去做各种事情。但这些线程要访问内存，而对它们来说，内存的每一个位置就像那些桃子。如果我们不协调线程之间的内存访问，程序就不会按预期工作。明白吗？

**学生**：大概吧。可为什么要在操作系统课上讲这个？这不就是应用程序编程吗？

**教授**：问得好！其实有几个原因。第一，操作系统必须用锁和条件变量这类原语来支持多线程应用，我们很快就会讲到。第二，操作系统本身就是第一个并发程序——它必须极其小心地访问自己的内存，否则会冒出一堆奇怪又可怕的事情。真的，场面会相当惨烈。

**学生**：我明白了。听起来挺有意思。我猜还有更多细节吧？

**教授**：确实有……
